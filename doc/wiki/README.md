# Oxidus Wiki

The source for <https://oxidus.online/>, built with
[Astro Starlight](https://starlight.astro.build).

## Layout

```text
doc/wiki/
├── astro.config.mjs           # site config, sidebar, Shiki grammars
├── public/                    # static assets served at the site root
└── src/
    ├── assets/                # images imported by pages
    ├── components/
    │   └── class-browser/     # the API-reference components used by daemon pages
    ├── content/docs/          # every page
    │   ├── guides/            # getting started, contributing, preferences
    │   ├── systems/           # how a subsystem works
    │   └── daemons/           # per-daemon API reference
    ├── grammars/              # lpc and lpml TextMate grammars for code blocks
    └── styles/custom.css
```

Starlight looks for `.md` or `.mdx` files under `src/content/docs/`, and each
file becomes a route based on its path. The three sidebar sections are
autogenerated from the directories above, so a new page appears without touching
`astro.config.mjs`.

## Commands

Run from this directory:

| Command | Action |
| :------ | :----- |
| `npm install` | Install dependencies |
| `npm run dev` | Dev server at `localhost:4321` |
| `npm run build` | Build to `./dist/` |
| `npm run preview` | Preview the build locally |

## Writing Pages

Read `.claude/skills/wiki-writing/SKILL.md` at the repository root before adding
or editing a page. The rules that bite most often:

- **Canadian English** throughout -- colour, behaviour, defence, catalogue.
  Prefer `-ize` over `-ise`.
- Fence LPC as ` ```lpc ` and LPML as ` ```lpml `; both grammars are registered
  in `astro.config.mjs`.
- Refer to lib files by **lib-relative** path (`std/living/body.lpc`), never a
  host-absolute one. Source files use the `.lpc` extension.
- Every page needs `title` and `description` frontmatter.
